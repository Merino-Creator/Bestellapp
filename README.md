# 🍕 Delivery App
 
Eine responsive Bestell-App für einen fiktiven Lieferdienst, entwickelt mit HTML, CSS und JavaScript.
 
Das Ziel dieses Projekts war es, eine moderne Bestelloberfläche anhand eines Figma-Designs nachzubauen und dabei grundlegende sowie fortgeschrittene JavaScript-Konzepte praktisch anzuwenden.
 
---
 
## 🚀 Funktionen
 
- Dynamische Darstellung der Speisekarte
- Produkte zum Warenkorb hinzufügen
- Anzahl der Produkte erhöhen und verringern
- Produkte aus dem Warenkorb entfernen
- Automatische Berechnung von Einzelpreisen und Gesamtsumme
- Responsives Design für Desktop- und Mobilgeräte
- Sticky-Warenkorb auf größeren Bildschirmen
- Optimierte mobile Warenkorbansicht
- Umsetzung eines vorgegebenen Figma-Designs
---
 
## 🛠️ Verwendete Technologien
 
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox
- CSS Grid
- Responsive Webdesign

Dieses Projekt diente dazu, meine Kenntnisse in der Frontend-Entwicklung zu vertiefen und die Arbeitsweise einer modernen Bestellanwendung besser zu verstehen.
 
Während der Entwicklung habe ich gelernt:

Besonderes Augenmerk lag auf:
 
- einer klaren Projektstruktur

## 📱 Responsive Design
 
Die Anwendung wurde für verschiedene Bildschirmgrößen optimiert.
 
Auf **Desktop-Geräten** wird der Warenkorb dauerhaft sichtbar angezeigt, während für kleinere Displays eine angepasste **mobile Version** entwickelt wurde, um auch auf Smartphones eine komfortable Bedienung zu ermöglichen.
